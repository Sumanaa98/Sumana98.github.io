Basic Web Design Project - Portfolio Website

Designed a responsive website for a fictional business concept using HTML, CSS, and JavaScript.

Project Overview

This project was a part of my BSc Web Design and Development coursework, focusing on building a responsive and user-friendly website for a fictional business. The website was designed to showcase key business services and provide a smooth browsing experience across devices.

Key Features

  • Fully responsive layout compatible with desktops, tablets, and mobile devices.
  • Modern design with CSS animations and hover effects.
  • Interactive elements like dynamic navigation and call-to-action buttons.

Technologies Used

  • HTML
  • CSS
  • JavaScript
